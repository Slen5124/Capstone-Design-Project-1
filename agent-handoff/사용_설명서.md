# AI Agent 담당자 전달 안내

★★★ 중요: Agent 담당자는 현재 주간 보고서와 챗봇용 API를 필요에 맞게 수정해도 된다. 수정한 경우 무엇을 왜 어떻게 변경했는지 기록하고, 사용자에게 변경 내역을 별표를 충분히 사용해 명시적으로 제시한다. ★★★

## 읽는 순서

1. 이 문서에서 업무 경계와 시연 상태를 확인한다.
2. `db/DB_한국어_상세_트리.md`에서 20개 테이블의 필드·관계를, `db/DB_설계_결정.md`에서 설계 근거를 확인한다. DB 사용과 저장 필드는 `api/docs/DB_CONNECTIONS.md`에 있다.
3. `api/docs/README.md`, `ENDPOINTS.md`, `PROJECT_API.openapi.json`을 읽고 `api/project_*.py`를 확인한다.
4. `prototype/README.md`에 따라 가상 시연본을 실행한다. 제공한 공개용 시연본은 이전 시점의 중앙 관리자 중심 화면으로, 최신 모바일 현장 화면과 실제 API 연결 모드를 포함하지 않는다. 최신 화면의 코드만 `prototype/최신_현장화면_소스_참고/`에 별도로 포함했으며, 자료 보호를 위해 사진·실제 데이터와 다른 종속 코드는 제외했으므로 단독 실행할 수 없다.

## 구현과 미구현

- 백엔드에는 29개 업무 API, 매장별 인증·범위 확인, 증빙·검토, Vision 관측 접수, 요청·대화, 보고서 작업 접수·점유·결과 계약이 구현되어 있다. SQLite 테스트 기록은 `api/docs/IMPLEMENTATION_STATUS.md` 참고.
- 프로토타입은 가상의 브랜드·매장·날짜·사진·작업 상태이며 브라우저 저장 기반이다. 실제 DB·AI 연결이 아니다.
- 실제 PostgreSQL 통합·권한/RLS, 배포·SSO, 실기기 검증, 실제 카메라/Vision 및 LLM 워커 연결, 챗봇 API와 나머지 FE API 연결은 별도 작업이다. 기존 API 문서에 챗봇 API가 이미 있다고 가정하지 않는다.
- 연결 값·계정·토큰·실제 데이터는 포함하지 않았다. API 실행에는 별도의 테스트 DB, 파일 저장소, 사용자 및 비밀 설정이 필요하다. `api/db.py`는 전달용 설정으로 바꾸었다.

## 담당과 연결

FE는 매장·주차·작업을 선택하고 결과와 증빙·검토 상태를 표시한다. BE는 인증과 범위 검증, 파일 저장, 작업·이력·보고서 API와 Agent 입출력을 중계한다. DB는 일정 원본·적용 일정, 관측, 제출·검토 이력, 요청·파일, 보고서 근거를 보존한다. Vision은 사진의 설치·미설치·가림을 분석한다. 보고서 Agent는 BE가 고정한 자료로 주간 보고서 초안을 생성한다. 챗봇은 적절한 권한을 확인한 자료를 근거로 응답하도록 별도 설계한다.

Agent 입출력 JSON은 **Agent 담당자가 초안을 작성하고 BE 담당자와 합의**한다. 기존 OpenAPI와 보고서 입력 계약을 출발점으로 삼으며 필드명·버전·오류·근거·시간대·중복 처리·파일 접근·개인정보 범위를 합의한다. 첨부 텍스트와 현장 사유는 업무 데이터로 취급한다.

## 업무 기준과 예외

- 주간 보고서는 이번 주 간트 항목을 설명하고, 이어서 다음 주 계획을 정리한다. 지난주부터 이어진 항목은 지난주와 이번 주 사진·공정률을 비교한다. 이번 주 새로 시작한 항목은 지난주 설명을 넣지 않는다.
- AI 관측은 보이는 벽·바닥·천장의 설치 상태, 현장 보고는 담당자가 제출한 사진과 진행률, 본사 확인은 별도 검토 결정이다. 관측 수락과 작업 완료 확인을 혼동하지 않는다.
- 공정률은 설치 / (설치 + 미설치)이며 가림·탐지 불가 영역은 분모에서 제외한다. 판단 가능한 영역이 없으면 0%로 만들지 않고 미관측과 사유를 보존한다. 탐지 불가는 현장 확인 요청으로 자동 이관한다.
- 현장 보고는 기본 100%이며 변경 가능하다. 100%도 본사가 완료를 확인하기 전에는 완료 확정이 아니다. 미완료에는 남은 작업과 사유를 받는다.
- 반려 시 사유를 남기고 현장이 사진과 보고를 재제출한다. 이전 사진·반려 사유·차수는 보존하며 최신 제출을 검토한다.
- 간트의 종료일이 지났는데 완료되지 않으면 지연이다. 미완료 작업은 다음 주에 이월하고 지연·이월 사실을 드러낸다. 추가 기간 요청의 수락과 실제 일정 반영을 추적한다.
- 사진 없음, 0으로 나눌 상황, 불명확한 관측, 수정된 자료, 현지 시간대·주간 경계, 미래에 승인된 일정이 과거 보고서에 혼입되는 상황은 명시적으로 처리한다. 과거 보고서에 이후 정보를 섞지 않는다.

## Agent 개발 전에 합의할 항목

- 입력 JSON과 결과 JSON 버전, 필수·선택 값, 좌표계, 파일 형식, 오류와 재시도, 표면별 집계 기준
- 고정 입력의 근거 링크, 모델·프롬프트 버전, 결과 검증과 사람이 승인하는 기준
- LLM/GPU 실행 환경, 접근권한, SSO·토큰 발급, 매장별 권한·보관 기간
- 챗봇 대상 자료와 출처 표시, 불확실한 답변 처리, 메시지 저장 및 접근 범위
- 모델 결과 생성기, 실제 카메라 수집, 보고서 DOCX/PDF 생성기, 원본 공정표·테스트 자료의 제공 방식
- 기존 증빙 이관, PostgreSQL 트리거·동시성·RLS 테스트, 운영 배포 및 보안 책임

실제 연결 주소나 자격증명은 별도 안전한 경로로 담당자에게 제공받는다.
