오류 후보와 검수 기록

왼쪽에서 결과를 선택하세요.
    벽 누락·라벨 충돌 판정은 확인된 기준과 정합 근거가 필요합니다. 기준이 없거나 정합이 불안정하면 추가 확인 대상으로 남습니다.

    영역 비교·정합 근거

    픽셀 채움 진단은 제출된 좌표를 그대로 채웠을 때 기준 영역과 겹치는 비율을 계산한 보조 검사입니다. 잘못된 폴리곤을 고치거나 벽·천장의 정답을 검증한 결과는 아닙니다. 수치는 Pillow 픽셀 채움 기준이며 이 화면의 경계 픽셀과 차이가 있을 수 있습니다.

    중복·충돌 도형 중 남길 도형 선택

    사진에서 같은 객체를 중복 표시한 것이 맞는지 확인하고, 좌표와 라벨이 올바른 도형을 직접 선택하세요. 점수가 높은 도형을 자동으로 선택하지 않습니다. 둘 다 틀렸다면 선택하지 않고 추가 확인으로 남기세요. 수정본은 별도 초안으로 저장됩니다.

    원본 JSON은 보존됩니다. 수정 초안도 검수 전에는 학습용 정답으로 사용하지 않습니다.

    검수 기록 저장으로 라벨이 자동 변경되지는 않습니다. 수정본 링크가 있을 때 별도로 내려받아 확인할 수 있습니다.
