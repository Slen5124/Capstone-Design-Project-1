# 검수 사용 설명서 (한 장으로 끝내기)

> 검수 화면 오른쪽 위 **"사용법"** 으로 언제든 열 수 있습니다. 갱신: 2026-10-23.
> 명령은 모두 **PowerShell**, 폴더 `D:\work\project\전처리된 데이터` 에서 한 줄씩. (`cd /d`, `rem`, `%VP%` 는 cmd 문법이라 안 됩니다)

## 1. 전체 순서도

```
 0. (처음 한 번) auto 전체
      .\vision_preprocessing\vp.cmd auto --config vision_preprocessing\config\<현장>.json --label <이름>
 0'. (암호 ZIP 현장만, 한 번) 사진 미리 풀기 — 다른 창에서, 검수와 동시에 가능
      .\vision_preprocessing\vp.cmd prewarm --run <RUN>
          │
          ▼
 [A] 검수 서버 켜기 → 브라우저 http://127.0.0.1:8765/todo
      .\vision_preprocessing\vp.cmd review --run <RUN>
          │   할 일 화면을 위에서부터 (번호 순서 = 작업 순서)
          ▼
 ① 구도(view) 경계 제안 · 구도 승인
 ①' 카메라 위치가 다른 사진 (구도 안에 섞임)  ← 추천(초록) 버튼: 기간에서 빼기 / 새 구도로 나누기 / 기준 사진 바꾸기
 ② ROI 그리기 · ROI 승인              ← 구도 × 벽마다. 라벨보다 반드시 먼저
 ③ ROI 겹침 · ROI 검수 결과 · 구도 사이 빈 시간 · 카메라 밀린 날
 ④ 대상/공정 적용 여부 승인            ← 안 하는 공정(예: 이미 끝난 천장)은 not_applicable
          │   서버 창 Ctrl+C
          ▼
 [B] 표본·앵커·초안 다시 계산 → 끝나면 [A]
      .\vision_preprocessing\vp.cmd auto --run <RUN> --stage samples,drafts,todo
          │
          ▼
 ⑤ 직접 그릴 기준(앵커) 사진           ← 구도마다 처음·중간·마지막 날
          │   Ctrl+C → [B] → [A]
          ▼
 ⑥ 자동 초안 검수 (Grid)               ← 앞 날짜부터
 ⑦ 승인된 라벨 중 확인이 필요한 것     ← 거꾸로 가거나 급변한 라벨
          │   ⑥이 0건이 될 때까지 [B] → [A] 반복
          ▼
 [C] 학습 데이터 만들기 → <RUN>\exports\<날짜>_train_full
      .\vision_preprocessing\vp.cmd auto --run <RUN>
```
- **auto 와 검수 서버는 동시에 못 켭니다.** 서버 창에서 Ctrl+C 후 auto. (prewarm 은 동시에 가능)
- 할 일 화면 맨 위 "할 일 N건"이 0 이면 그 단계 끝. 회색 칸은 참고용(할 일 아님).

## 2. 화면과 조작

### 편집 화면 (`/`)
| 조작 | 방법 |
|---|---|
| 이름 | 오른쪽 위 검수자 칸에 이름(필수). 승인 기록에 남습니다 |
| 사진 이동 | 왼쪽 목록 클릭, 키보드 ← / → |
| 확대 · 이동 | 마우스 휠 / Shift+드래그 또는 휠 버튼 드래그 / `fit` |
| 대상 선택 | 오른쪽 위 대상(W01 …) → 공정(벽 = wall_board_installation, 천장 = ceiling_panel_installation) |
| 기준 사진과 비교 | `compare with reference` 체크 |
| 폴리곤 그리기 | 버튼(+ installed 등) → 꼭짓점 클릭 → **Enter 또는 더블클릭으로 닫기**, Backspace = 점 하나 취소, Esc = 그리기 취소 |
| 꼭짓점 수정 | 해당 칸(ROI 칸 / 라벨 칸)의 `Edit vertices` → 꼭짓점 드래그, 변 더블클릭 = 점 추가, 꼭짓점 우클릭 = 삭제, 폴리곤 안 클릭 후 Delete = 폴리곤 삭제 |
| 빠른 승인 | 저장된 라벨이 맞으면 키보드 **A** = 승인하고 다음 사진 |

### 할 일 화면 (`/todo`)
카드마다 사진 위에 ROI(색 선)가 그려져 있고 버튼이 붙어 있습니다. **"열기 → W01"** 은 그 벽이 선택된 채 편집 화면을 엽니다.
버튼 종류: `구도 기간에서 빼기` · `새 구도로 나누기 (ROI 옮긴 초안)` · `기준 사진 바꾸기 (ROI 옮긴 초안)` · `확인 (그대로 둠)` · `구도 학습에서 제외` · `ROI 그대로 써도 됨` · `확인 (제외 유지)` · `앞 사진과 같음 → 복사+승인` · `선택한 것 새 ROI로 옮겨 다시 승인`.

### Grid (편집 화면 왼쪽 `Grid view`)
왼쪽 필터(구도, 날짜, samples, draft)가 그대로 적용됩니다. 썸네일을 훑고 → `select photos not yet approved` → targets 체크 → `Same as previous photo → approve (selected)`.

## 3. ROI 규칙
- **벽 전체**를 감쌉니다: 아직 안 붙은 곳, 가려진 곳 포함. 가림 때문에 줄이지 않습니다.
- 문·창·설비처럼 **끝까지 남는 개구부만** `Draw exclusion`(이유 door_opening / window / fixture / not_in_scope).
  나중에 막을 **임시 통로는 ROI에 포함**(막히기 전 = not_installed).
- 같은 구도의 **어느 사진에서든** 고칠 수 있습니다(좌표가 같음). 저장하면 **그 구도 전체** ROI가 바뀝니다.
  - ✗ 카메라가 밀린 날(흔들림 보고에 나온 날) 사진에서는 고치지 않기.
  - ✗ 다른 벽의 폴리곤이 섞이면 저장이 거부됩니다(벽을 바꾸기 전에 저장했는지 확인). 단순 겹침은 확인 창 후 저장 가능.
- 비슷한 구도는 `copy ALL targets' ROIs from` → `Copy as drafts` 후 꼭짓점만 고치기.
- 이 구도에서 안 보이는 벽은 `안 보임 (not visible in this view)`.
- **라벨을 그린 뒤 ROI를 고치면 그 구도의 라벨 승인이 풀립니다** → 할 일 "ROI가 바뀌어 다시 승인할 라벨"에서
  `선택한 것 새 ROI로 옮겨 다시 승인` 한 번. 그래서 **이상한 ROI는 라벨 전에** 고치는 게 일이 적습니다.

- **카메라 위치 검사(auto 의 `align` 단계)**: 모든 사진을 기준 사진과 맞춰 봅니다. 카메라가 움직인 구간은 할 일
  "카메라 위치가 다른 사진" 카드로 나오고, 버튼으로 고칩니다. 나누기·기준 사진 바꾸기는 ROI를 새 위치로 옮긴 **초안**을
  만들므로 "ROI 승인"에서 확인 후 Approve. 빛(낮·밤) 차이만 있는 사진은 두 번째 비교로 걸러집니다.
  **라벨을 그리기 전에** 이 카드부터 처리하세요(나중에 나누면 그 구간 라벨을 다시 승인해야 함).

## 4. 설치율(라벨) 규칙
- 칠할 것: `+ installed`(석고보드가 붙은 곳), `+ not_installed`(골조·단열재만), `+ occluded`(사람·리프트·자재가 벽을 가림),
  `+ undeterminable`(어두움·흐림 등 판단 불가, 이유 선택).
- **전체가 한 상태면 폴리곤 없이** `fill rest of ROI` = installed 또는 not_installed. 일부만 다르면 그 부분만 그리고 나머지는 fill.
- 가림은 export 때 SAM3 물체(사람·도구·자재)를 자동으로 빼므로, **큰 가림만** 직접 그리면 됩니다.
- 저장 `Save label draft` → 확인 → `Approve label`. 사진 밖 점·꼬인 폴리곤은 자동 보정되고 메시지가 뜹니다(정상).
- ROI도 같은 순서: `Save ROI draft` → 버튼이 바로 `Approve ROI v(새 번호)` 로 바뀜 → 승인. (저장 직후 사진 목록의 "stale" 표시는
  뒤에서 사진을 다시 맞추는 중이라는 뜻이며 몇 초 뒤 사라집니다.)
- 앵커: **구도마다 처음·중간·마지막 날 사진**. 앞 사진과 같은 상태면 할 일 ⑤에서 체크 → `앞 사진과 같음 → 복사+승인`.
  이미 그린 앵커는 할 일 카드에 **초록 테두리 + 칠한 라벨**로 남아 있어 나머지 사진과 바로 비교할 수 있습니다.
- 편집 화면 위쪽 **`비교 보기` + "앞에 그린 라벨 사진 (같은 벽)"**: 옆 화면에 같은 구도에서 이 벽을 이미 그린 가장 가까운 사진이
  그 라벨과 함께 뜹니다(사진을 넘기거나 벽을 바꾸면 따라 바뀜). "기준 사진"을 고르면 예전처럼 기준 사진 비교.
- 초안 검수는 **반드시 앞 날짜부터 고치고 뒤쪽을 일괄 승인** (순서가 바뀌면 고치기 전 값이 복사됨).
- 설치율 = **보이는 부분 중** 붙은 비율. 면적·매장 전체·공정률이 아닙니다. 사람이 다 가려도 0 % 로 칠하지 말고 occluded/undeterminable.

## 5. 하면 안 되는 것
- 원본 ZIP, `automatic_results`, qa_v2/qa_v3 코드 수정 · 사진/라벨을 외부 서비스에 업로드.
- 자동 초안을 보지 않고 일괄 승인 · 시스템 이름(auto, system, claude)으로 승인.
- 카메라가 움직인 날을 같은 구도로 두기 → 구도 경계 제안을 수락하거나 새 구도로 나누기.
- auto 실행 중에 검수 서버 켜기(잠금으로 막힘. 다른 PC가 남긴 잠금만 `--force-unlock`).

## 6. 문제가 생기면
| 증상 | 할 일 |
|---|---|
| 저장이 안 됨 | 화면 아래 **빨간 메시지**(클릭해야 닫힘)를 읽기. 모든 실패는 `<RUN>\review_errors.log` 에 남음 → Claude 에게 "로그 봐줘" |
| 버튼이 안 보임 | 오른쪽 위 대상·공정이 맞는지, 사진이 구도에 속하는지(View 칸) 확인. 서버를 최신 코드로 다시 켜기 |
| 사진이 늦게 뜸 | prewarm 실행(1장). 한 번 연 사진은 다음부터 바로 |
| "version N is not current" | 화면보다 새 버전이 저장돼 있다는 뜻. 내가 방금 저장한 버전이면 확인 창에서 **확인** = 그 버전으로 바로 승인. 남이 저장한 버전이면 화면이 새로 고쳐지니 보고 다시 승인 |
| "Discard unsaved drafts?" | 저장 안 한 그림이 있다는 뜻. 취소하고 먼저 Save |
| 할 일이 줄지 않음 | 승인까지 했는지(저장만 하면 "저장됨·승인 필요"). 앵커·초안 목록은 auto [B] 후 새로 계산 |
| `run is in use by 'review server'` | 서버 창 Ctrl+C 후 auto |
| PowerShell 오류 `rem`, `%VP%` | cmd 문법. `.\vision_preprocessing\vp.cmd ...` 로 |
