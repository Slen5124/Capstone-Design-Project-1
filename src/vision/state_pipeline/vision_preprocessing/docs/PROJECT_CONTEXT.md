# 프로젝트 컨텍스트

갱신일: 2026-11-02. 현재 선택은 **DINOv2 + UPerNet**이다.

## 흐름

1. RGB 사진과 기존 라벨을 로컬에서 정리한다. 구도·대상 ID·ROI·가시성·시공 상태는 사람이 검수한다.
2. `vision_preprocessing`에서 마스크와 데이터 분할을 export한다. 자동 초안/전파 라벨과 사람 정답은 구분한다.
3. 동결 DINOv2 특징 → 특징 피라미드 → UPerNet → 대상·상태 헤드를 학습한다. 모델 입력은 RGB 사진이다.
4. 추론 마스크와 고정 ROI로 관측 설치율과 근거를 계산해 `vision_output.json`을 출력한다.
5. 백엔드가 저장·조회·공정표 연결을 담당하고 Agent가 근거 기반 보고서·질의응답을 담당한다.

## 보존할 원칙

- 관측 설치율은 매장 전체 공정률이나 실제 면적이 아니다. 가림·판단 불가는 0%로 바꾸지 않는다.
- 다른 구도나 다른 대상은 같은 ROI로 비교하지 않는다.
- 현재 학습 코드의 단일 작업 기본값은 4클래스, `--activity all`은 벽·천장을 포함한 6클래스다.
- LOSO 고정 규격과 DINOv2 연구 비교 구현은 재현성을 위해 유지한다. 과거 결과를 새 설정의 성능으로 재사용하지 않는다.
- 현재 공개 백엔드는 문서와 SQL이다. 웹 프로토타입은 가상 자료를 사용하며 실서비스 연동 완료를 뜻하지 않는다.
- 원본 사진·라벨·실험 결과·가중치는 로컬 보존, Git 공개 제외. 커밋·푸시는 사용자가 수행한다.

상세 흐름은 저장소 `docs/planning/current-vision-pipeline.md`, 검수·export는 `AI_HANDOFF.md`, 새 현장 사용은 `NEW_SITE_GUIDE_ko.md`를 참고한다.
