자동 전처리 실행 편의 기능

설치 위치: D:\work\project\전처리된 데이터

1. 탐색기에서 전처리_실행.cmd를 두 번 클릭하면 실행 메뉴가 열립니다.
   대표 13장, 처음 100장, 전체, 지정 구간, 이어하기를 선택할 수 있습니다.
   메뉴를 열기만 해서는 전체 실행을 시작하지 않습니다.

2. CMD에서 직접 실행하는 예
   cd /d "D:\work\project\전처리된 데이터"
   전처리_실행.cmd -Mode Smoke
   전처리_실행.cmd -Limit 100
   전처리_실행.cmd -Start 100 -Limit 100
   전처리_실행.cmd -MaxMinutes 60

   Start는 원본 사진 목록의 시작 위치입니다. 0은 처음입니다.
   목록은 사이트별로 번갈아 배치한 안정된 순서입니다. Start 100은 앞의
   100장을 건너뜁니다. 같은 Start/Limit을 반복하면 같은 사진을 처리합니다.
   Limit 0은 시작 위치부터 끝까지입니다. 원본 ZIP 목록이 바뀌면 순서도
   달라질 수 있으므로 실행 결과의 선택 목록을 기준으로 구간을 관리하세요.

3. 실행 창에서 실시간 진행 확인
   준비 단계와 JSON 연결 색인 단계, 사진 처리 단계를 구분해 표시합니다.
   처리 수/전체 수, 진행률, 경과 시간, 속도, 예상 남은 시간, 분류 수와
   디스크 여유를 확인할 수 있습니다. 예상 남은 시간은 현재 단계 기준이며
   전체 실행 완료까지의 확정 시간이 아닙니다. 초반 예상 시간은 변동합니다.
   원본 JSON 전체 색인은 최초 전체 실행에서 시간이 걸릴 수 있습니다.

4. 다른 CMD 창에서 상태 확인
   전처리_상태.cmd
   전처리_상태.cmd -Watch
   전처리_상태.cmd -RunDir "D:\...\automatic_results\run_실행시각"

   -Watch는 2초마다 상태를 확인하고 완료/중단 상태가 되면 종료합니다.
   상태 창에서 Ctrl+C를 누르면 상태 표시만 종료합니다.

5. 안전하게 중단하고 이어하기
   전처리_상태.cmd -Stop
   전처리_실행.cmd -Resume "D:\...\automatic_results\run_실행시각"

   -Stop은 최근 진행 중 실행의 STOP 파일을 만들어 중단을 요청합니다.
   현재 작업과 체크포인트 저장이 끝날 때까지 실행 창을 유지하세요.
   체크포인트는 기본 20장 단위이며 -CheckpointEvery 10으로 바꿀 수 있습니다.
   -Stop으로 중단하면 처리 중인 결과까지 체크포인트에 저장합니다.
   Ctrl+C나 강제 종료 때는 마지막 체크포인트 이후 최대 20장 정도를 다시
   처리할 수 있습니다. 원본 데이터를 수정하는 것은 아닙니다.
   이어하기는 원본 ZIP, 기준, 코드와 저장 옵션의 일치 여부를 검사합니다.
   Resume와 Start/Limit/Mode/Layout/CheckpointEvery는 함께 지정하지 않습니다.
   이어하기 기능을 추가하기 전의 v3 결과 폴더는 이어할 수 없습니다.
   이 편의 기능을 설치한 뒤 생성한 실행 폴더부터 이어하기를 지원합니다.

6. 실행 범위와 공간 보호
   -MaxMinutes 60: 약 60분이 되면 현재 작업을 저장하고 안전 중단합니다.
   -MinFreeMB 2048: 디스크 여유를 2 GiB 이상 남기는 조건으로 실행합니다.
   기본 디스크 여유 기준은 1024 MiB입니다. 충분한 공간이 없으면 진행을
   중단하고 이미 저장된 결과를 보존합니다. 압축 ZIP 출력이 기본입니다.
   -Workers 2: 동시 작업 수. 1~8 지정 가능하며 디스크와 메모리에 따라
   무조건 크게 설정한다고 빨라지지는 않습니다.

7. 최종 결과
   automatic_results\run_실행시각 아래에 분류별 JSON, classification.csv,
   manifest.jsonl, summary.json, progress.json과 체크포인트가 저장됩니다.
   기본 ZIP 출력은 chunks\part_000001\annotations\auto_fixed.zip과 같이
   체크포인트별로 닫힌 ZIP 묶음을 저장합니다. 모든 part 묶음이 한 실행의
   결과이며 마지막 묶음만 골라 쓰지 마세요.
   원본 사진 ZIP과 JSON ZIP은 보존하고 사진 전체를 디스크에 풀지 않습니다.
   암호는 입력 프롬프트 또는 QA_ZIP_PASSWORD에서 받으며 저장하지 않습니다.
   자동 수정 결과는 시각적 정답을 보장하는 사람 검수 완료 데이터가 아닙니다.

분류 기준
   auto_fixed: 자동 수정 후 설정한 검사에 미해결 문제가 없음.
   kept: 어노테이션 변경 없이 설정한 검사에 미해결 문제가 없음.
   needs_review: 가능한 수정을 했지만 미해결 사유가 남음.
   rejected: 사진/JSON 손상 등으로 처리할 수 없음.
