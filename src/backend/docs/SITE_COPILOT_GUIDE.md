# ALOHA 매장 도우미 안내

## 답변 범위

도우미는 현재 선택한 매장과 공정표의 자료를 답변한다. 주차를 지정하면 그 주차를, 주차를 생략하면 화면에서 선택한 주차를 기준으로 본다. 다른 매장, 다른 회사의 요청 첨부, 카메라 인증 정보와 내부 저장 경로는 답변하지 않는다. 자료가 없으면 자료가 없다고 안내한다.

## 간트 일정 확인

간트 일정 화면에서 주차를 선택하면 그 주와 겹치는 작업을 확인할 수 있다. 계획 일정은 원본 공정표의 일정이고, 기간 연장이 본사에서 승인된 경우에만 적용 일정이 변경된다. 승인 전 요청은 공정표 날짜를 바꾸지 않는다.

## 작업별 검토

AI 관측 작업은 벽·바닥·천장 사진의 분석 결과와 오버레이를 확인한다. 현장 증빙 작업은 현장 관리자가 제출한 사진, 진행률, 선택 보고 문장을 확인한다. 본사는 증빙 수락과 작업 완료 확인을 별도로 기록한다. 100% 사진이 제출되었다고 자동으로 완료되는 것은 아니다.

## 현장 관리자 제출

AI가 분석하지 못했거나 현장 증빙으로 분류된 작업은 사진과 진행률을 제출한다. 보고 문장은 선택 사항이다. 반려되면 사유를 확인한 뒤 새 사진과 진행률을 재제출한다. 사진이나 분석 결과가 없는 작업은 보고서 최종 생성 전에 자료가 필요하다고 표시된다.

## 일정·작업 변경 요청

현장 또는 본사는 작업을 선택해 기간 연장, 일정 변경, 작업 변경 요청을 등록할 수 있다. 수신 본사의 승인 전에는 적용 일정이 바뀌지 않는다. 승인되면 적용 일정이 이후 주차 간트와 보고서에 반영되며, 원본 공정표의 계획 일정은 보존된다.

## 주간 보고서

매장 화면에서 **주간 보고서** 탭을 열고 원하는 주차를 선택하세요. 이미 저장된 보고서는 **생성된 PDF 열기**로 확인할 수 있어요.

새 PDF가 필요하면 **초안 만들기 · PDF**를 누르세요. 자료가 일부 빠져 있어도 초안을 만들 수 있어요. 필수 자료가 모두 준비되면 **최종 보고서 만들기**를 선택할 수 있어요. 생성이 끝나면 **생성된 PDF 열기**를 누르면 됩니다.

## 도우미가 할 수 없는 일

도우미는 제출, 승인, 반려, 일정 변경, 파일 업로드를 직접 실행하지 않는다. 필요한 화면과 절차를 안내한 뒤 사용자가 기존 버튼으로 명시적으로 실행해야 한다.

## 대화 내역과 이어지는 추천 질문

오른쪽 아래 프로젝트 도우미 버튼으로 대화를 연다. 질문과 답변은 현재 로그인 계정, 매장, 공정표 버전, 보고 주차별로 AWS에 시간순으로 저장된다. 같은 범위에서 대화를 다시 열거나 새로고침하면 저장된 내역이 복원된다. 오래된 내역은 대화 상단의 '이전 대화 더 보기'로 확인한다. 다른 주차나 다른 매장을 선택하면 해당 범위의 대화를 표시한다. 같은 시험 계정을 함께 사용하는 사람은 같은 계정의 대화 내역을 본다.

공정표가 연결된 매장에서는 Qwen이 현재 질문, 최근 질문, 공정표 작업명과 ID, 앞서 확인한 자료의 작업과 주차를 참고해 필요한 조회를 최대 네 건으로 나눈다. 백엔드는 각 조회를 현재 매장과 사용자 권한 범위에서 실행하고 수치·날짜·상태를 표시한다. 두 주차의 진행률 차이도 백엔드가 계산한다. 답변은 한국어 또는 영어로 표시하며, 인용한 제출·검토 문장은 원문을 유지한다. 답변 아래 추천 질문을 클릭하면 일반 질문처럼 전송된다.

“전에 조명 사진을 다시 요청한 이유가 뭐였지?”처럼 이전 대화를 묻는 질문은 같은 계정·회사·매장·공정표의 다른 주차까지 검색한다. 관련 대화 최대 3건을 날짜와 주차 정보와 함께 참고한다. 작업명이나 날짜를 같이 물으면 비슷한 기록을 구분하는 데 도움이 된다.
