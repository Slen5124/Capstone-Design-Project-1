# 시공 상태·진행 모니터링 선행연구 비교

작성일: 2026-11-02 · Team Aloha · 중간점검 선행연구 보완 자료

## 1. 비교 목적과 근거

본 과제는 **BIM·3D 정보가 없는 고정 카메라 환경에서, 검수한 대상별 ROI와 시공 상태 분할을 결합해 관측 설치 비율을 추정하고 새 현장 일반화 성능을 평가**한다. 모델 자체의 소개와 별개로, 같은 시공 모니터링 문제를 다룬 연구 세 편을 비교한다.

이 문서는 저장소의 개별 논문 리뷰와 현재 파이프라인 문서를 종합한 것이다. 세 논문의 전체 본문·실험표를 이번 작성 과정에서 새로 대조하거나 기존 방법을 재현한 것은 아니다. 공개 초록·미리보기 기반인 항목은 그 한계를 유지하며, 확인되지 않은 성능 수치를 채우지 않았다.

## 2. 방법 비교표

| 비교 항목 | Kropp et al., 2018 [1] | Wei et al., 2022 [2] | Pal et al., 2024 [3] | 본 과제 |
| --- | --- | --- | --- | --- |
| 해결 문제 | 실내 사진의 설계 요소를 특정하고 시공 상태 인식 | 실내 미장 영역 인식과 BIM 기반 진행 관리 | 요소 존재 여부를 넘어 작업 표면의 시공 비율 추정 | 고정 카메라 사진에서 대상별 관측 설치 비율 추정 |
| 주요 입력 | 실내 영상 시퀀스, 4D BIM | 현장 이미지, 촬영 위치 관련 정보, BIM | 여러 현장 사진, 4D BIM, 사진 기반 3D 정보 | RGB 사진, 검수한 구도·대상 ID·ROI, 학습용 상태 라벨 |
| 동일 대상 식별 | 영상과 BIM을 정합해 설계 요소에 연결 | 인식 영역을 위치·BIM 요소에 연결 | 3D·BIM 정합으로 요소와 작업 표면에 연결 | 구도별 대상 ID·ROI를 사람이 확정; 구도 변경 시 재검토 |
| 상태·영역 인식 | BIM에 연결된 요소의 시각적 상태 인식 | Mask R-CNN 기반 시공 영역 분할 | 정사영상의 작업 영역 분할; 기존 리뷰에서 Mask R-CNN 사용 확인 | 동결 DINOv2-B/14 + 학습 가능한 디코더·물체/상태 헤드 |
| 공간 처리 | BIM 좌표에 영상 연결 | 위치 정보와 BIM을 통한 공간 연결 | 3D 복원·정합 후 표면 정사영상 구성 | 기본 경로에 BIM·3D 복원·정사영상 없음 |
| 진행 정보 산출 | 요소·작업에 연결된 관측 상태 | 분할 결과를 BIM 요소·작업에 연결한 진행 정보 | 요소 표면과 작업 영역을 연결한 작업 비율 | ROI 내 설치 픽셀 / (설치 + 미설치 픽셀) |
| 측정 범위·분모 | 전체 본문에서 세부 정량 정의 추가 확인 필요 | 전체 본문에서 세부 비율 산식 추가 확인 필요 | 정사영상·요소 표면 기반; 세부 정규화는 본문 추가 확인 필요 | 가림·대상 아님을 제외한 관측 영역; 실제 면적·전체 공정률과 구분 |
| 대표 적용 대상 | 라디에이터·석고보드 벽 등 실내 요소 상태 | 실내 벽 미장 | 요소별 세부 작업 표면 | 벽·천장 설치 상태를 모델링; 현재 주 결과는 벽 설치율 |
| 본 과제에 주는 근거 | 대상의 위치 연결과 상태 인식을 분리해야 함 | 분할 마스크를 대상·작업 정보에 연결해야 함 | 비율의 좌표계·표면·분모 정의가 핵심임 | 초기 대상 등록과 상태 분할을 분리하고 제한된 관측 범위를 명시 |

본 과제에서 대상 ID·ROI는 모델의 추가 입력 채널이 아니라 **추론 마스크를 측정·추적할 때 결합하는 메타데이터**다. 공정표는 작업 매칭과 일정 비교에 사용하며 분할 모델이 직접 읽는 입력은 아니다.

## 3. 평가와 직접 비교의 한계

| 연구 | 기존 리뷰에서 확인한 평가 정보 | 직접 비교 시 주의점 |
| --- | --- | --- |
| Kropp et al., 2018 | 실내 작업 상태 평가; 공개 자료에는 라디에이터·벽 상태 영상 사례가 있음 | 전체 성능표를 확인하지 않아 수치 비교에서 제외 |
| Wei et al., 2022 | 공개 초록의 mAP 96.8% | 검출/분할 지표로, 설치율 MAE와 다른 지표. 세부 IoU 기준 추가 확인 필요 |
| Pal et al., 2024 | 공개 초록의 평균 절대 오차 6% 미만 | 평가 단위·정규화·데이터·기하 조건이 달라 우리 %p 오차와 직접 순위 비교 불가 |
| 본 과제 | 저장소 보고 기준 LOSO 벽 설치율 MAE 5.44%p, 벽 mIoU 63.6% | SITE_A·B·C macro 기준. 원자료 재계산 여부와 SITE_D 별도 집계는 결과 문서 참고 |

따라서 “기존 논문보다 정확하다”는 결론은 내리지 않는다. 본 과제의 정량 비교는 **동일 인코더·데이터 분할·학습 규격에서 디코더와 추론 방법을 바꾼 내부 실험**에 근거한다. 결과는 [LOSO 결과표](../planning/loso-results.md)에 정리했다.

## 4. 본 과제의 차별점과 검증 범위

| 주장 가능한 차이 | 검증 방법·근거 | 현재 한계 |
| --- | --- | --- |
| BIM 없이 고정 카메라와 검수 ROI를 사용 | 전처리 → 상태 분할 → 대상별 측정 경로 및 검수 기록 | 초기 대상 등록은 사람 작업이며 구도 변경 시 유지 관리 필요 |
| 새 현장으로의 일반화를 평가 | 현장 단위 LOSO, 시험 현장을 학습에서 제외 | 현장 4곳이며 주 macro는 3곳; 모든 현장에 대한 일반화 보장 아님 |
| 동결 인코더 위 디코더 기여를 비교 | UPerNet·MLP·DPT 3시드, Linear 1시드 | 새로운 인코더·디코더를 발명했다는 의미가 아님 |
| 관측 가능성에 따라 결과를 선택적으로 사용 | 확신도·가시성 기반 위험도-커버리지 분석 | 오프라인 분석이며 운영 임계값·검수 흐름의 통합 검증은 별도 |
| 실제 작업량과 영상 관측 비율을 구분 | 비율의 분모·대상 ID·가림 처리 명시 | 물리 면적·매장 전체 공정률에는 추가 기하 정보·작업 가중치 필요 |

현재 논문에서 중심에 둘 연구 질문은 다음과 같다.

> 제한된 현장 라벨과 동결된 범용 시각 인코더를 사용할 때, 디코더 선택과 추론·시간축 처리 방식이 처음 보는 현장의 관측 설치율 오차에 어떤 영향을 주는가?

ROI 정의와 라벨 품질, 현장별 편차, 가림·철거·작은 대상에서의 실패를 함께 보고한다. 새로운 구조의 제안 여부와 산업 데이터에서의 체계적 비교·한계 분석은 구분한다.
