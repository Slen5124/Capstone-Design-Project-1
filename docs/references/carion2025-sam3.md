## 한 줄 요약

짧은 개념 설명이나 예시로 지정한 대상들을 이미지·영상에서 찾아 분할하는 모델이며, 우리 데이터에서는 대상 마스크 초안을 만드는 보조 수단으로 해석한다.

## 다루는 문제

클릭으로 지정한 개별 물체를 분할하는 것에서 나아가, “이 개념에 해당하는 모든 대상”을 찾고 영상에서 연결하는 문제가 필요하다.

## 핵심 아이디어 / 방법

Promptable Concept Segmentation(PCS)은 텍스트의 짧은 명사구나 시각적 예시로 개념을 지정한다. SAM 3는 검출과 메모리 기반 추적을 결합하고, 개념의 존재 여부 판단과 위치 추정을 분리하는 presence head를 사용한다.

| 입력 | 출력 | 우리 사용 위치 |
| --- | --- | --- |
| 이미지·영상 + 개념 프롬프트 | 해당 개념의 인스턴스 마스크; 영상에서는 추적 정보 | 전처리의 대상 라벨 초안 |

사진에서 wall을 찾는 것과 그 벽이 보드 설치 완료인지 판단하는 것은 다른 과제다. 객체 마스크만으로 상태 정답이 완성되지 않는다.

## 실험 및 결과

논문은 PCS 과제와 SA-Co 벤치마크를 소개하고 이미지·영상의 개념 기반 분할을 평가한다. 이러한 결과는 건설 현장의 상태 라벨이나 전체 공정률 정확도를 검증한 것이 아니다. 조건이 다른 분할·추적 점수를 하나의 “시공 인식 정확도”로 환산하지 않는다. [논문 초록](https://arxiv.org/abs/2511.16719)

## 우리 프로젝트에 적용할 점

아래는 **논문 내용을 바탕으로 한 프로젝트 적용 해석이며, 원 논문에서 우리 현장 데이터로 검증한 결과가 아니다.**

1. 과거 라벨 초안 제작에 SAM3를 사용했다면, 데이터 제작 과정의 출처로 인용을 유지한다.
2. 사람이 대상 경계·상태·가림을 검수한 라벨과 자동 생성 초안을 구분한다.
3. 검수된 상태 라벨을 DINOv2+분할 디코더의 학습에 사용한다.
4. **이 리뷰 추가는 SAM3 실행 코드를 현재 저장소에 다시 도입한다는 뜻이 아니다.** 현재 운영 모델과 데이터 제작 이력을 분리해서 기록한다.

## 한계 및 주의점

- 개념 분할 결과가 프로젝트의 벽 ID·구도 ID를 자동 보장하지 않는다.
- 의미상 비슷한 재료, 보호막, 가려진 표면에는 사람 검수가 필요하다.
- 자동 라벨로 만든 시험 정답만 사용하면 라벨 제작 모델의 오류를 그대로 평가 기준으로 삼을 수 있다.
