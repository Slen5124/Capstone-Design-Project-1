## 추진 배경

- 애슬레저 시장 경쟁 심화로 오프라인 플래그십 매장이 브랜드 경험·커뮤니티(요가 클래스 등) 거점으로
  진화하면서, 매장 내 고객 행동을 정량 측정할 필요성이 커짐
- 기존 출입 인원 카운팅(Prodco Traffic Counter)은 "몇 명이 들어왔는가"만 알려줄 뿐,
  "어디에 머물고, 얼마나 오래 보며, 어떤 동선으로 결제까지 이동하는가"를 설명하지 못함
- 버카다(Verkada) CCTV(IP Camera)에 Edge Server를 연동해 존별 체류·유입률·동선 전환을 측정한
  선행 데이터에서 **입구-계산대 대각선 구조**, **카테고리 분산 배치** 등 구조적 매출 손실 요인이 확인됨
- 알로요가 매장 역시 여성 고객 비중이 높고 피팅룸·클래스 공간 등 비판매 구역의 체류가 구매 전환에
  미치는 영향이 커, 동일한 분석 프레임으로 데이터 근거 기반 운영 개선안 도출이 필요함

## 목표

알로요가 매장의 버카다 CCTV(IP Camera)·센서 데이터를 활용하여 **존 단위 체류·동선·전환 구조**를
진단하고, Edge 서버에 의한 **실행 가능한 매장 운영 최적화 가이드라인과 KPI 체계**를 수립한다.

## 세부 내용

### 1. 방문 퍼널 분석
매장 앞 통행량 → 입장 → 순방문객 → 존 체류로 이어지는 단계별 이탈률 산출 및
유입률(Capture Rate) 기준선 설정

### 2. 체류 귀속률(Attribution Rate) 진단
총 체류시간 대비 존 카운터에 집계되지 않는 미측정 시간 비율을 산정하고,
피팅룸·계산대·중앙 통로 등 측정 사각지대 도출

### 3. 존 진단 매트릭스
존별 침투율(Penetration) × 평균 체류시간 2축 분석으로
**스타존·통과존·틈새존·데드존** 4분면 분류 및 진열 생산성 평가

### 4. 동선 전환 네트워크 분석
첫 방문/마지막 방문 존 비율과 존 간 이동 데이터를 분석하여 계산대까지 도달하지 못하는
동선 구조를 규명하고, 플로어 플랜 오버레이로 공간적 원인 진단

### 5. 고객 세그먼트 분석
성별·연령대·시간대·요일별 방문 및 체류 패턴 분석과 피크 시간 기반 인력 배치 시뮬레이션

### 6. 측정 정합성 검증
동일 카운터의 이중 집계, 누락 카운터, 중복 존 명칭, 대시보드 KPI 산출 오류 등
데이터 신뢰성 결함을 점검하는 자동화 리포트 개발

### 7. KPI 체계 및 재무효과 추정
전략·운영·진단 3단계 KPI 프레임 설계, 체류시간 탄력성 모델을 적용한
매출 상승 및 비용 절감 시나리오와 **90일 실행 로드맵** 제시

### 8. 알로요가 브랜드 특성 반영
요가 클래스·커뮤니티 이벤트 운영 시간대의 매장 체류·전환 기여도 분석 및
온라인 채널(aloyoga.com) 고객 여정과의 연계 방안 검토

## 기대효과

- 존별 체류·동선 데이터에 근거한 진열 및 레이아웃 재배치를 통해 데드존을 회복하고 객단가 상승
- 유입률(Capture Rate) 1%p 개선 효과 등 매장 외부 레버의 정량적 우선순위를 도출하여
  마케팅 투자 효율 제고
- 피크 시간·요일 기반의 인력 운영으로 서비스 밀도를 개선하고 인건비 효율화 달성
- 추가 하드웨어 투자 없이 설정 변경과 진열 개선만으로 실행 가능한 90일 실행 로드맵 확보
- 매장 성과 측정 표준(KPI 정의 및 정합성 검증 프로세스) 수립으로
  향후 신규 매장 확장 시 재사용 가능한 운영 체계 구축

## 용어 정리

| 용어 | 정의 |
| --- | --- |
| 유입률 (Capture Rate) | 매장 앞 통행량 대비 실제 입장 인원 비율 |
| 침투율 (Penetration) | 전체 방문객 중 특정 존을 방문한 비율 |
| 체류 귀속률 (Attribution Rate) | 총 체류시간 중 존 카운터로 설명되는 시간의 비율 |
| 스타존 | 침투율·체류시간 모두 높은 존 |
| 통과존 | 침투율은 높으나 체류시간이 짧은 존 |
| 틈새존 | 침투율은 낮으나 체류시간이 긴 존 |
| 데드존 | 침투율·체류시간 모두 낮은 존 |
