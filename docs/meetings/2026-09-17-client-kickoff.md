## 회의 요약

기존 고객 동선 분석 방향에서 글로벌 매장 공사 관리로 프로젝트 방향이 바뀌었습니다. 이번 미팅에서는 현장 사진 기반 공정 모니터링과 개략 공사비 산정의 두 과제를 제안받았습니다. 9월 19일 팀 회의에서 과제별 논문 2편, 입력·처리·출력 구조, 필요한 자료와 구현 우선순위를 검토합니다.

## 1. 회의 목적 및 배경

산학 교수는 기업 문제를 학생팀과 연결하고 AI 팩토리 플랫폼·GPU를 지원합니다. 앤디는 Alo Yoga의 건설 프로젝트 매니저로, 부동산 계약부터 설계·시공사 선정, IT 장비 설치와 인수인계까지 매장 오픈 과정을 담당합니다. 연구 재단 지원 프로그램은 약 12주 진행되며 멘토 보고서 5회와 최종 발표가 필요합니다. 멘토비·수료증·GPU 지원 범위는 프로그램 안내로 확인합니다.

앤디에 따르면 Alo Yoga는 미국과 아시아·태평양 지역에서 매장을 확장하고 있습니다. 여러 국가의 공사 현황과 비용을 원격으로 파악해야 하는 것이 이번 과제의 배경입니다. 회사 연혁·매장 수·가격 등 소개 수치는 멘토 발언으로 기록합니다. 매장에는 CCTV, 방문자 카운터, AP, RFID, POS와 클라우드·VPN이 사용되지만, 이번 과제에 제공할 데이터와 접근 범위는 확인이 필요합니다.

## 2. 논의 내용

### 과제 A · 현장 사진 기반 공정 모니터링

해외 현장 방문과 시공사 주간 보고에 의존하는 문제를 설명했습니다. 15분 간격 스냅샷을 남기는 옥스블루(OxBlue)를 참고 사례로 제시했습니다. 같은 위치의 과거·현재 사진에서 벽·바닥·천장 등의 변화를 찾고 공정표와 비교해 진행 상황과 지연 의심을 근거 사진과 함께 보고하는 기능을 원합니다. 매일 오전 8시 이메일 보고와 후속 질문에 답하는 기능도 제안되었습니다.

필요한 자료는 촬영 시각·위치가 있는 이미지, 위치별 작업명과 예정일이 포함된 공정표, 검증용 현장 판정 기록입니다. 원본 이미지의 양과 촬영 위치의 지속성, FTP/JSON 전달 방식, API 접근 권한, 공정표 형식과 '진행률 %'의 기준은 확인이 필요합니다. 현재 사용 중인 OxBlue 기능과 이미지 추출 범위를 확인한 뒤 개발 범위를 정합니다.

### 과제 B · 개략 공사비와 공급업체 견적

신규 입지 검토 시 국가·현장별 공사비와 기간을 빠르게 추정하기 어렵다는 요구가 제시되었습니다. 홍콩 매장의 예산 300만 달러 대비 실제 600만 달러 소요는 멘토가 설명한 사례이며, 비용 범위와 증가 원인은 자료 수령 후 확인합니다.

위치·규모·공사 범위·마감 수준 등 초기 입력으로 개략 금액 범위를 제시하고, 도면·사진·스캔, 수량·사양을 바탕으로 공급업체가 단가와 납기를 확인해 견적을 보정하는 흐름을 검토합니다. 국가·시점별 가격 변동 반영도 희망 기능입니다. 과거 견적과 실제 비용, 통화·기준일·지역·면적·공종·수량·사양, 업체의 견적 회신 방식이 필요합니다. 가격 데이터 사용 권한, 도면/BIM 제공 여부, 업체 참여와 가격 API 계약은 확인이 필요합니다.

### 기술·일정 관련 발언과 확인 사항

- **모델·실행 환경:** 교수는 로컬 오픈소스 모델(Ollama로 실행하는 모델, Gemma 등)과 제공 GPU 활용, 최종 추론 단계의 상업용 AI API 사용 제한을 제시했습니다. 'GPT-3.5급'의 의미와 개발 단계 외부 API 허용 여부는 재확인합니다. 중국계 모델 사용 지양도 언급되어 후보별 사용 가능 여부를 확인합니다.
- **분석 방법:** 조명·타일·석고보드·프레이밍 등의 객체 탐지, 공사 문서 검색을 위한 RAG, 이메일 질문·답변을 처리하는 에이전트가 제안되었습니다. 개발 순서와 필수 범위는 토요일에 정합니다.
- **촬영 방식:** 고정 카메라 스냅샷과 현장 순회 촬영을 검토합니다. 360도 카메라 왜곡과 일반 광각 카메라 적용 가능성이 언급되었으나, 현장 구조와 사진을 확인한 뒤 장비를 정합니다.
- **데이터·평가:** 학습 데이터 10만 건 이상, 7:2:1 분할, 정확도 90~95%(최소 80~85%)가 목표로 제시되었습니다. 실제 원본·라벨 수, '파인튜닝 20%'의 용도, 현장·시간 단위 분할과 과제별 평가 지표는 확인해야 합니다. 합성 데이터는 학습 보조 후보로 두고 독립 테스트 자료와 구분합니다.
- **지원 자원:** GPU는 `NVIDIA A6000, VRAM 62GB`로 메모되었고, 성과에 따라 H100 지원 가능성이 언급되었습니다. 장비 모델·실제 VRAM·접근 방법은 확인이 필요합니다.

앤디는 한국 매장의 주간 보고서와 현장 사진 샘플을 공유하기로 했습니다. 팀장은 회의 이해 요약을 이메일로 보냅니다. 자료 수령 전까지 기능 범위는 잠정안입니다.

## 3. 9월 19일(토) 팀 회의 사전 준비안

토요일 회의 전까지 과제별 SCI(E)급 논문 2편씩, 총 4편을 조사합니다. 아래 준비 방식은 팀 내부 검토안이며, 논문과 개인별 담당은 아직 확정되지 않았습니다.

### 공통 조사 형식 · 논문당 1장

1. **논문과 문제:** 제목·저자·연도·학술지·DOI/링크·SCI(E) 등재 근거와 해결하려는 현장 문제.
2. **입력:** 사진·영상·도면·BIM·공정표·견적 등 사용한 데이터의 종류와 규모.
3. **방법:** 전처리, 모델·규칙, 비교 과정을 3~5단계 흐름으로 설명.
4. **출력·평가:** 산출물, 정답 자료, 평가 지표와 논문에 제시된 수치의 의미.
5. **우리 프로젝트 적용:** 활용할 단계, 추가 자료, 12주 내 구현이 어려운 부분.

### 과제 A · 현장 사진과 공정표

- 조사 대상: 사진·영상으로 시공 변화를 검출하거나 관찰한 공정을 계획 일정과 비교한 연구 2편.
- 토요일에 설명할 예시 흐름: `날짜·위치가 있는 사진 + 작업별 공정표 → 변화/작업 인식 → 계획 대비 상태 판단 → 근거 사진이 포함된 리포트`.
- 확인 항목: 고정·순회 촬영 조건, 가려진 작업의 처리, 진행률 %와 지연 여부의 정답 작성 방식.
- 추가 확인: 매일 오전 8시 보고와 이메일 추가 질의에 필요한 속도·근거 제시 가능 여부.

### 과제 B · 개략 공사비와 공급업체 견적

- 조사 대상: 초기 조건으로 개략 공사비를 추정하거나 도면·수량과 단가를 연결한 연구 2편.
- 토요일에 설명할 예시 흐름: `위치·면적·공사 범위·사양 또는 도면 → 수량/유사 사례 확인 → 개략 금액 산출 → 공급업체 확인·수정`.
- 확인 항목: 필요한 과거 실적 데이터, 국가·시점별 가격 반영, AI 추정값과 공급업체 견적의 구분.
- 추가 확인: 논문이 초기 개략 추정과 도면 기반 상세 수량 산출 중 어느 단계를 다루는지.

## 4. 토요일 회의에서 정리할 결과물

1. **논문 요약 4장:** 과제별 2편. 위 공통 조사 형식에 맞춰 입력·방법·출력과 우리 프로젝트에 필요한 자료를 설명한다.
2. **과제별 파이프라인 1장씩:** 실제 확보 가능한 입력 → 처리 단계 → 출력 예시를 그린다. 과제 A는 변경점·공정표 비교·근거 사진, 과제 B는 초기 입력·개략 금액·업체 확인 과정을 담는다.
3. **데이터 요청 목록 1장:** 이미지와 촬영 위치, 해당 기간 공정표·주간 보고서, 과거 견적과 실제 비용, 도면, 공급업체 견적서 양식의 제공 여부와 요청 담당자를 적는다.
4. **검증 계획 1장:** 과제 A에서 '변화 검출'과 '지연 판단'을 구분하고, 과제 B에서 개략 추정값과 업체 회신값을 구분한다. `90% 정확도`가 어느 단계의 어떤 지표인지 질문으로 남긴다.
5. **월요일 프로포절 초안:** 문제 정의, 기존 방식과 차이, 논문 4편의 방법, 12주 간트 차트, 팀원 역할, 데이터 의존성, 첫 시범 범위를 포함한다.
