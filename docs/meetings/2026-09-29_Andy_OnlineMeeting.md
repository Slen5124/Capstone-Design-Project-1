## 📌 결정 사항
* **프로젝트 스코프 확정:** 단순 객체 탐지(Object Detection)를 넘어, **현장 데이터를 기반으로 공정 진행률을 판단하고 AI 리포트 생성 후 LLM을 통해 질의응답하는 End-to-End 시스템** 구축을 최종 목표로 함.
* **데이터 활용 방향:** 360도 카메라 데이터는 왜곡 문제 등으로 배제하고, 기존 평면 데이터인 **OXBLUE 12개 프로젝트 전체를 우선 활용**하여 학습 및 검증 진행.
* **데이터 분할(Split) 방식:** 모델 과적합 방지를 위해 이미지가 아닌 **프로젝트 단위(예: 7:2:2 등)로 Train / Validation / Test 셋을 분할**하기로 함.
* **추가 데이터 요청 프로세스:** 무작정 요청하는 것을 지양하고, 1차 실험 후 발견된 문제(예: 저조도 환경에서 성능 저하)와 원인 분석을 근거로 부족한 데이터를 요청하기로 합의.
* **오프라인 미팅 필수 진행:** 연구재단 수료 기준 충족을 위해 **총 2회의 오프라인 현장 미팅**을 진행하기로 확정 (팀원 전체 참석 의무 아님).
