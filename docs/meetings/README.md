# 회의록

팀 회의와 멘토링 내용을 기록하는 공간.

## 작성 규칙

1. 회의가 끝나면 **당일 중** 담당자가 작성한다.
2. 파일명은 `YYYY-MM-DD-<주제>.md` 형식으로 짓는다.
   - 정기 회의: `2026-09-23-weekly.md`
   - 멘토링: `2026-10-02-mentoring.md`
   - 특정 주제 논의: `2026-10-10-zone-definition.md`
3. 커밋 메시지는 `docs: YYYY-MM-DD <주제> 회의록 추가` 형식으로 쓴다.
4. **결정 사항**과 **액션 아이템**은 반드시 채운다. 이 두 항목이 회의록의 핵심이다.
5. 액션 아이템은 담당자와 기한을 명시하고, 다음 회의에서 이월 여부를 확인한다.
