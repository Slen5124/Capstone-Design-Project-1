# 과제 변경 경위와 기획 자료 요약

갱신일: 2026-11-02 · 현재 결정: A안 확정·DINOv2 + UPerNet

공식 과제명은 **Development of an AI-Powered Construction Management Support System for Global Retail Stores**, 팀명은 **Team Aloha (알로)**다. 이 문서는 팀 회의록과 비공개 멘토 미팅 자료·수행계획서에서 과제 이해에 필요한 내용을 요약한 공개용 설명이다.

## 1. 과제가 바뀐 경위

기존 과제는 알로요가 매장 고객 동선·존 분석이었다. 이후 글로벌 매장 공사관리 지원을 대상으로 다음 두 안을 비교했다.

| 검토안 | 주요 내용 | 필요한 자료·검증 관점 |
| --- | --- | --- |
| A안 | 현장 사진으로 시공 상태를 분석하고 공정표와 연결해 보고서·질의응답 제공 | 현장 사진과 촬영 맥락, 작업·구역 정보, 공정표 등 |
| B안 | 개략 공사비와 공급업체 견적 지원 | 과거 예산·최종 비용·견적·단가 등 비용 자료와 검증 기준 |

[2026년 9월 19일 팀 내부 회의](https://github.com/Slen5124/Capstone-Design-Project-1/blob/main/docs/meetings/2026-09-19-weekly.md)에서 A안을 우선 추진하기로 했다. 당시에는 A안 수행에 필요한 자료를 알로요가 측에서 받기 어려우면 B안으로 전환할 가능성도 검토했다. 이는 당시 데이터 확보에 따른 조건을 기록한 내용이다. 현재 사용자 확인에 따른 진행 과제는 **A안으로 확정**됐다.

A/B안 선택 경위의 근거는 팀 내부 회의록이다. 멘토 미팅 자료는 두 안의 선행연구·필요 데이터·예상 입출력을 설명하고 팀의 A안 선호를 전달하기 위해 준비한 자료로 구분한다.

## 2. 비공개 PDF에서 참고한 내용

| 자료 | 문서에 반영할 핵심 내용 |
| --- | --- |
| 멘토 미팅 자료 | A/B안 조사 결과, 각 안의 입력·출력과 데이터 요구, 팀의 Vision AI 관심 및 제한된 파일럿 기간을 고려한 A안 선호 |
| 수행계획서 | 공식 과제명, 글로벌 리테일 매장의 공사관리 지원이라는 목적, 사진 분석에서 공정표 연결·보고서·질의응답으로 이어지는 전체 흐름 |

멘토 자료의 A안 선호와 실제 팀의 선택을 연결해 설명한다. B안은 비용 이력과 견적 자료를 확보하고 검증하는 부담도 비교 대상으로 다뤘다. 원본에 공개 가능 여부를 묻는 내용이 있어도 이를 공개 허가로 해석하지 않는다. 두 PDF 원본은 공개하지 않는다.

수행계획서의 계획은 구현 완료를 뜻하지 않는다. 개발 범위와 미정 항목은 아래 최신 팀 설명을 우선 적용한다. 원본의 연락처·학번 등 개인 정보는 공개용 요약에 포함하지 않는다.

## 3. 현재 프로젝트에 적용할 기준

- 라벨 생성 모델 실행은 현재 공개 범위에서 제외한다. 기존 라벨은 실제 생성 출처를 보존하고 구도·대상·ROI·가시성·상태를 사람이 검수한다.
- 검수된 RGB 사진과 상태 마스크로 DINOv2 + UPerNet을 학습한다. 구도·대상 ID·ROI·가시성·상태 라벨 검수와 데이터 분할은 유지하며, 운영 결과는 관측 설치율과 근거로 전달한다.
- 전후 사진 매칭 후보는 LoMa-L과 RoMa v2다. 같은 대상을 확인하고 별도 기하 정합·검증을 통과한 경우에만 공통 영역을 비교한다.
- 실제 사진은 학습을 마친 선택 모델로 처리한다. 자체 코드가 분석 결과와 근거를 JSON으로 정리해 서버로 전달하고, 서버가 검증·저장·조회한 결과를 Agent가 보고서·질의응답에 활용한다. 전후 비교 결과도 같은 전달 흐름에 포함한다.
- 현재 모델은 벽·천장 상태를 구분한다. 관측 설치율과 실제 공정률의 환산 기준은 별도 합의한다.
- DINOv2 기반 LOSO 비교 규격은 연구 재현용으로 보존한다. 2026-11 결과로 UPerNet을 기본 모델로 확정했고, 시간축 보정 대신 확신도 기반 사람 검수를 쓰기로 했다. 새 실험은 코드·설정·데이터 버전을 기록한다.

고정된 역할은 이윤한(비전 팀 리드·모델 학습·추론·학습 테스트), 강태웅(비전 데이터 전처리), 강원준(Agent·RAG), 김병조(DB·백엔드)다. 과거 회의록과 일정 이미지의 세부 담당 표기는 당시 기록으로 보존한다.

기술별 인풋·아웃풋은 [현재 비전 파이프라인](current-vision-pipeline.md), 구현 산출물과 순서는 [Git 산출물 기획](git-deliverables-plan.md)에 정리했다.
