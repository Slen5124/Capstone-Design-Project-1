# 구현 범위와 역할

갱신일: 2026-11-02. 이전 모델 비교·일정 설명을 현재 선택에 맞춰 정리했다. 과거 일정은 현재 완료 상태를 의미하지 않는다.

| 영역 | 구현 방향 | 담당 |
| --- | --- | --- |
| 데이터 전처리 | 구도·대상 ID·ROI·상태·가시성 검수와 학습 데이터 export | 강태웅 |
| 모델 학습·평가 | 동결 DINOv2 + UPerNet, 대상·상태 헤드, 현장 단위 평가 | 이윤한 |
| 추론·측정 | RGB → 상태 마스크 → ROI 관측 설치율·품질·근거 JSON | 이윤한 |
| 백엔드 | 결과 검증·저장·조회, 작업/공정표 연결, 모델·자료 버전 관리 | 김병조 |
| Agent | 정형 결과 조회·문서 검색·보고서·질의응답·근거 검증 | 강원준 |
| 공개 시연 | 가상 자료 기반 UI, 실제 API 연결은 별도 통합 작업 | 팀 공동 |

백엔드 공개 브랜치는 문서와 초기 SQL을 제공한다. 별도 운영 서버 구현과 저장소에서 실행 가능한 기능을 구분한다.
시연은 브라우저 로컬 저장을 사용하며 자동 분석·알림·서버 동기화는 아직 연결하지 않았다.

통합은 비전 출력 계약 확인 → 백엔드 저장·조회 → Agent 근거 생성 → UI 연결 순서로 검증한다.
관측 설치율을 전체 공정률이나 지연으로 환산하는 규칙은 작업 ID·공정표·측정 기준과 함께 별도 합의한다.
실제 날짜·담당별 일정은 팀 일정에서 관리하며 이 정리 작업에서 임의로 새 날짜를 확정하지 않는다.
