# LOSO 실험 결과표와 재현 자료 안내

작성일: 2026-11-02 · 결과 기준: 2026-11-01 · Team Aloha

## 1. 결과의 출처와 검증 상태

이 문서는 저장소 [README](../../README.md), [현재 비전 파이프라인](current-vision-pipeline.md), [실험 규격](../../src/vision/state_pipeline/vision_preprocessing/train/loso/PROTOCOL.md)에 보고된 수치를 모은 결과 요약이다. 문서 작성 기준 커밋은 `c51e96062090159bef024c8c1f85d75cbbf3148c`이며, 이는 각 학습 실행의 코드 커밋을 대신하지 않는다.

**이 문서를 만들면서 40회 실험을 재실행하거나 비공개 예측 CSV 전체에서 수치를 다시 계산하지 않았다.** 아래 숫자는 현재 저장소의 보고값이다. 표의 전사·문서 간 일관성 확인과 원자료 재계산은 구분한다. 실제 실행 버전·데이터 해시·결과 파일을 연결하는 절차는 8절에 적었다.

## 2. 고정된 실험 조건

| 항목 | 설정 |
| --- | --- |
| 규격 | `loso-v1`; 변경 시 새 버전으로 구분 |
| 연구 대상 | 학습하지 않은 현장의 벽 설치율 추정 |
| 인코더 | 동결 DINOv2 ViT-B/14 + registers (`vit_base_patch14_reg4_dinov2.lvd142m`) |
| 디코더 | UPerNet / MLP / DPT / Linear |
| 출력 | 물체 8클래스 + 상태 6클래스(벽·천장 설치/미설치, 가림, 대상 아님) |
| 입력·학습 | RGB 1024×576, batch 4, AdamW, lr 1e-3, weight decay 1e-4, OneCycle, 15 epoch |
| 모델 선택 | 마지막 epoch; validation 최적 epoch는 보조 분석 |
| 분할 | SITE_A~D 중 한 현장을 통째로 test로 남기는 4-fold LOSO |
| 반복 | UPerNet·MLP·DPT 각 3시드(0, 1, 2); Linear는 시드 0 |
| 실행 수 | 3디코더 × 4현장 × 3시드 + Linear 4현장 = 40회 |
| 정답 | hold-out 현장의 사람 검수 라벨; 현장별 표본·대상 제한은 PROTOCOL 3절 적용 |
| 집계 | SITE_A·B·C 동일 비중 macro; 시드별 macro를 계산한 뒤 평균 ± 표준편차 |
| 별도 사례 | SITE_D는 철거·재시공 사례로 별도 보고; 주 macro에 포함하지 않음 |
| 정밀도 | AMP 사용. DPT 디코더·출력 헤드는 FP16 오버플로 수정 후 FP32로 12회 재학습했다고 기록됨 |

사람 검수 라벨·전파 라벨·약라벨의 학습 가중치와 validation 인접 날짜 제외 규칙은 원 규격을 따른다. 이 문서는 기존 데이터 분할과 제외 규칙을 변경하지 않는다.

## 3. 측정값과 지표 정의

관측 설치 비율 `r = N_installed / (N_installed + N_not_installed)`로 정의한다. `N`은 해당 ROI 안의 픽셀 수다. 가림·대상 아님은 분모에서 제외한다. 분모가 없거나 품질 조건을 충족하지 못하는 관측의 처리는 평가·운영 규격에 명시해야 한다.

| 지표 | 의미·단위 | 해석 |
| --- | --- | --- |
| 벽 설치율 MAE | 날짜×벽 행별 `100 × abs(r_pred - r_gt)`의 평균, %p | 5.44%p는 설치 비율의 평균 절대 차이. 정확도 94.56%라는 뜻이 아님 |
| 벽 mIoU | 해당 벽 상태 클래스의 IoU 평균, % | 픽셀 상태 분할 평가. 정확한 클래스·가림 제외·집계는 평가 코드와 원자료 확인 |
| ±10%p 이내 비율 | 설치율 절대 오차가 10%p 이하인 평가 행 비율 | 어느 정도의 오차 범위 안에 드는지 평가 |
| 완료 판정 F1 | 설치율 0.9를 완료 기준으로 사용한 F1 | 설치 비율 기준의 분류 평가이며 실제 공정 준공 승인과 구분 |
| 위험도-커버리지 | 확신도 순으로 일부 행을 선택했을 때의 MAE와 선택 비율 | 오차 감소와 자동 처리 범위 축소를 함께 보고 |

픽셀 비율은 원근·촬영 범위의 영향을 받는다. 이 실험의 결과를 실제 표면적, 매장 전체 공정률 또는 전체 서비스 정확도로 해석하지 않는다.

## 4. 주 결과: 디코더 비교

**표 1. 학습하지 않은 현장의 벽 설치율 추정. MAE 단위는 %p이며 낮을수록 좋다.**

| 디코더 | 보고된 파라미터 규모 | SITE_A | SITE_B | SITE_C | Macro A·B·C | SITE_D 별도 | 벽 mIoU | ±10%p 이내 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| UPerNet | 4.10M | 4.45 ± 0.17 | 4.10 ± 0.49 | 7.76 ± 0.35 | **5.44 ± 0.32** | **9.33** | **63.6%** | 80.4% |
| Linear | 0.05M | 5.45 | 5.12 | 7.02 | 5.86 | 15.08 | 58.1% | **80.9%** |
| DPT | 4.50M | 6.23 ± 0.50 | 4.55 ± 0.34 | 7.33 ± 0.42 | 6.04 ± 0.29 | 15.29 | 61.7% | 78.8% |
| MLP | 1.05M | 7.68 ± 0.55 | 5.17 ± 0.12 | **6.70 ± 0.49** | 6.52 ± 0.28 | 10.55 | 57.8% | 75.8% |

- ±는 시드 간 표준편차이며 신뢰구간이 아니다. Linear는 1시드이므로 ±를 적지 않았다.
- SITE_D·mIoU·허용 오차 비율의 시드별 세부값은 요약 출처에 없으므로 새로 채우지 않았다. 최종 제출 시 원 결과에서 집계 범위를 확인한다.
- 파라미터는 원 규격의 디코더 구성 규모를 전사한 값이다. 동결 인코더를 포함한 전체 모델 크기로 설명하지 않는다. 어댑터·헤드 포함 범위는 `resources.json`과 계산 코드로 확인한다.
- UPerNet은 주 macro가 가장 낮지만 SITE_C에서는 MLP가 더 낮다. 모든 현장에서 UPerNet이 최상이라고 주장하지 않는다.
- UPerNet 완료 판정 F1은 기존 문서에서 **0.92**로 보고했다. 모델별·현장별 F1 원표가 없어 이 문서에서는 단독 보조 보고값으로만 남긴다.
- 이 표는 벽 결과다. 6클래스 출력이나 천장 라벨의 존재만으로 천장 성능까지 검증됐다고 주장하지 않는다.

## 5. 통계 비교와 민감도 분석

**표 2. UPerNet 대비 MAE 차이. 양수는 비교 모델의 오차가 더 큼을 뜻한다.**

| 비교 | 보고된 차이 (%p) | 95% 신뢰구간 | 보고된 해석 |
| --- | --- | --- | --- |
| MLP − UPerNet | +1.08 | [0.64, 1.57] | 해당 부트스트랩 조건에서 UPerNet 우세 |
| DPT − UPerNet | +0.60 | [0.19, 1.01] | 해당 부트스트랩 조건에서 UPerNet 우세 |
| Linear − UPerNet | +0.12 | [−0.46, 0.72] | 차이가 통계적으로 확인되지 않음; 공통 시드 0 비교 |

날짜×벽 행을 짝지은 부트스트랩(B=10,000), 현장별 층화 macro 규격에 따른 보고값이다. 표 1의 다중 시드 평균과 표 2의 비교 표본은 같다고 가정하지 않는다. 특히 Linear의 +0.12는 표 1의 5.86−5.44와 다른 공통 시드 비교이므로 서로 대체하지 않는다.

같은 벽의 인접 날짜는 상관될 수 있다. 현재 행 단위 재표집의 신뢰구간을 시간·현장 수준의 모든 불확실성을 포함한 것으로 확대하지 않는다. 필요하면 블록/군집 단위 분석을 후속 규격으로 추가하고 기존 결과와 구분한다.

**표 3. 사전 지정 예외 목록을 제외한 보조 결과.**

| 디코더 | 주 결과 MAE (%p) | 예외 제외 MAE (%p) |
| --- | --- | --- |
| UPerNet | 5.44 | 5.17 |
| Linear | 5.86 | 5.55 |
| DPT | 6.04 | 5.77 |
| MLP | 6.52 | 6.23 |

예외 제외 결과는 주 결과를 대체하지 않는다. 포함·제외 표본 수와 제외 목록 버전은 최종 제출 자료에 연결해야 한다.

## 6. 추가 실험: 추론·시간축·선택적 보고

**표 4. UPerNet 추가 실험의 보고값. MAE 단위는 %p.**

| 방식 | MAE | 기본 대비 차이 | 해석 |
| --- | --- | --- | --- |
| 기본 추론 | 5.44 | — | 비교 기준 |
| 반전·다중 배율 추론 | 5.45 | +0.01 | 전체 평균 개선 없음 |
| 작은 ROI 확대 추론 | 5.67 | +0.23 | 전체 평균 악화 |
| 단순 인과 시간축 보정 | 6.38 | +0.94 | 전체 평균 악화 |
| 가시성 인지 인과 보정(VCC) | 5.76 | +0.32 | 단순 인과 보정보다 낮으나 기본보다 악화 |
| 확신도 상위 50% 행만 선택 | 4.32 | −1.12 | 평가 행의 절반만 사용한 선택적 보고 분석 |

앞의 다섯 행은 기존 문서의 실험 요약 명칭을 사용했다. 정확한 `inference × temporal` 조합과 평가 행 수는 `pipeline_table.csv`에서 최종 대조한다. 확인 전에는 이 표를 완전한 요인별 ablation 표로 설명하지 않는다.

확신도 상위 50%는 **오프라인 위험도-커버리지 결과**다. 평가 집합 전체를 쓰는 기본 MAE와 동일 커버리지의 개선이 아니다. 이 결과만으로 신규 사진에서 작동하는 자동 보고 임계값이 확정되거나 운영 적용이 완료됐다고 볼 수 없다. 운영 기준은 validation에서 정하고 보류율·오차를 별도로 확인한다.

## 7. 연구 결과와 운영 성능의 구분

| 항목 | 연구 평가 경로 | 현재 운영 추론 경로에서 확인된 차이 |
| --- | --- | --- |
| 날짜별 집계 | 날짜×대상 평균 | 날짜×대상 중앙값 |
| 결측 처리 | 이전값/초기 0 보충 경로 존재 | 보류·null 유지 |
| 완료 기준 | 0.9 기준 F1 | 0.98 이상 두 관측일 조건의 이벤트 |
| 확신도 | 평가 행 순위 기반 위험도-커버리지 | 품질 플래그·검수 조건을 실제 전달 흐름에 연결해야 함 |

비교 근거: [연구 시간축 처리](../../src/vision/state_pipeline/vision_preprocessing/train/loso/temporal.py), [운영 추론 처리](../../src/vision/state_pipeline/vision_preprocessing/train/infer_core.py).

따라서 MAE 5.44%p와 F1 0.92는 위 연구 규격의 보고값이다. 운영용 집계·보류·완료 규격으로 동일 자료를 다시 평가하기 전에는 서비스 검증값으로 제시하지 않는다. 고정된 연구 규격을 운영 코드에 맞춰 소급 변경하지 않는다.

## 8. 원자료 재계산과 제출 준비

실행 환경·데이터 준비는 [DATA_SETUP.md](../../src/vision/state_pipeline/vision_preprocessing/train/loso/DATA_SETUP.md)를 따른다. 해당 환경에서 `src/vision/state_pipeline`을 작업 위치로 사용한다. 아래 경로는 설명용 자리표시자이며 실제 서버 주소·접속 정보를 포함하지 않는다.

```bash
# 이미 완료한 실험의 결과 디렉터리로 표를 다시 생성한다. 학습 재실행 명령이 아니다.
python -m vision_preprocessing.train.loso report --results <실험결과_폴더> --out <재계산_출력폴더> --lang ko
```

이 명령은 본 문서 작성 중 실행하지 않았다. 원자료 접근 권한이 있는 담당자가 실행 후 아래 항목을 확인한다.

| 필요한 증빙 | 연결할 파일 | 확인 내용 |
| --- | --- | --- |
| 실행 이력 | 실행별 `config.json`, `environment.txt`, `DONE.json`/`FAILED.json` | 실제 코드·가중치·데이터 해시, 실행 완료·수치 안정성 |
| 분할 | `split_manifest.json` | hold-out 현장 유입 없음, 사람/전파/약라벨 구분 |
| 정답·예측 | `photo_rows_*`, `daily_rows_base_*` CSV | 평가 단위, 행 수, 결측·예외 처리 |
| 주 결과 | `main_table.csv`, `macro_table.csv` | 표 1·3의 수치 및 시드 집계 |
| 통계 비교 | `bootstrap.csv` | 표 2의 표본·시드·구간 일치 |
| 추론 비교 | `pipeline_table.csv`, `risk_coverage.csv` | 표 4의 조합·커버리지·평가 행 수 |
| 완료·자원 지표 | `events.csv`, `resources.csv` 및 실행별 평가 파일 | F1 집계, 파라미터 범위, 추론 비용 |

최종 제출 전 확인 사항:

- [ ] 40개 실행의 유효 결과와 DPT 수정 후 실행 여부 확인.
- [ ] 각 표의 원 CSV·실행 ID·규격 버전·코드 및 데이터 해시 연결.
- [ ] 현장별 사람 검수 사진 수와 실제 날짜×대상 평가 행 수 기재.
- [ ] 예외 포함/제외와 SITE_D 별도 집계 근거 확인.
- [ ] mIoU·완료 F1·허용 오차 비율의 클래스·시드·현장 집계 확인.
- [ ] 재계산 표와 본 문서 수치 일치 확인 후 검증 일자·담당자 기록.
- [ ] 운영 추론 평가 결과는 별도 표로 작성.

공개 문서에는 익명화한 요약만 사용한다. 사진·라벨·가중치·원본 실행 로그·예측 CSV는 기존 저장소 정책에 따라 공개하지 않는다. 평가자에게 필요한 원자료는 기업 승인과 접근 권한을 확인한 제한 공유 경로에서 제공한다.
