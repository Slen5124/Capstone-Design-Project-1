# Git 산출물과 통합 순서

갱신일: 2026-11-02. 기본 비전 모델은 DINOv2 + UPerNet이다.

## 현재 공개 산출물

- `src/vision/state_pipeline/`: 모델 독립 전처리·검수·export, 학습·추론·LOSO 평가 코드.
- `docs/public/`, `src/backend/sql/`: 백엔드 설명과 초기 DB 스키마. API 실행 코드는 별도 관리.
- `prototype/public-demo/`: 가상 자료 기반 웹 UI 시연. 브라우저 저장을 사용하며 실제 서버·AI 연동은 별도 구현.
- `src/llm_agent_module/examples/`: 로컬 RAG 개념 검증 예제.

## 통합 우선순위

1. 비전 `vision_output.json`의 대상·시간·모델·상태·품질·근거 필드와 백엔드 계약을 맞춘다.
2. 합성 결과의 API 수신 → DB 저장 → 조회가 동일한지 확인한다.
3. Agent가 조회 결과·문서 근거로 답변하고 수치·날짜 불일치를 표시하는지 확인한다.
4. 시연 UI를 실제 조회 API와 연결한다. 가상 결과와 실제 분석 결과를 구분해 표시한다.
5. 검수된 라벨로 학습한 DINOv2 + UPerNet 결과(LOSO 평균 5.44%p)를 연결하고 동일한 절차를 반복한다. 확신도가 낮은 항목이 사람 검수 화면으로 가는지도 확인한다.
6. 큰 인코더 채택 여부와 추가 데이터 재학습 결과는 모델·라벨 버전을 올려 같은 계약으로 교체한다.

현장/대상/촬영 시각, 모델·라벨·ROI 버전, 비교 기준, 품질 사유와 근거 파일 참조를 계약에 포함한다.
전체 가림·대상 불일치·공정표 매핑 없음·잘못된 JSON·근거 부족 사례도 확인한다.

## 공개 범위

사진·영상·기업 보고서·라벨·마스크·가중치·자동 생성 실험 결과는 로컬 또는 승인된 저장소에 보관한다.
웹 시연의 공개용 자료에만 경로별 예외를 두고 전체 파일 형식의 제외 규칙을 해제하지 않는다.
LOSO 연구 규격은 고정된 기록이며 변경할 때 새 버전을 사용한다. 운영 모델 선택으로 이전 결과를 재해석하지 않는다.
