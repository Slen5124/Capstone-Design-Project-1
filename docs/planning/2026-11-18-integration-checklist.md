# 통합 검증 체크리스트

1. 격리된 PostgreSQL과 파일 저장소를 준비하고 테스트 사용자·매장별 권한을 확인한다.
2. 현장 사진 제출 → 본사 반려 → 재제출 → 완료 확인에서 기록과 사진이 유지되는지 확인한다.
3. 일정·작업 변경 요청의 결정·적용, 원본 일정 보존, 중복 요청과 동시 처리를 확인한다.
4. Vision 입력·분석 결과·관측 불가 이관이 같은 매장과 작업을 가리키는지 확인한다.
5. 주간 보고서 생성·근거·지난주 비교·실패 복구와 챗봇 답변의 권한 및 근거를 확인한다.
6. 브라우저·휴대폰과 서버의 실패 응답, 파일 접근, 배포·백업·복구를 확인한다.

검증 결과는 환경·날짜·기대값·실제값·통과/실패/미실행을 구분한다. SQLite의 로컬 테스트 성공을 실제 PostgreSQL이나 운영 환경 검증으로 간주하지 않는다.
