3. 제출과 요청 파일 저장, 증빙 제출·반려, 요청별 대화·결정·적용 API 연결. 동일 요청 동시 수락과 교차 매장 접근 차단 검증.
4. 카메라와 AI 대표 사진 수집, Vision 분석과 작업 매핑. 관측 불가와 실제 0%를 구분하고 원본·모델·수정본 추적.
5. 보고서와 챗봇 허용된 근거를 묶어 조회하고 AI 초안·본사 승인·Word 출력·질문 보관을 연결.
6. 적용 전 검증 복제 PostgreSQL에 003·후속 DDL 검증. 기존 보고서 파일 연결 보존, 연결 풀 사용자 컨텍스트와 파일 인가 확인.
