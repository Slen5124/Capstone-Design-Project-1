# 업로드 전 보안 검사

검사일은 2026-11-08 KST다. 검사 범위는 이번에 추가하는 ERD 자료 폴더와 루트 README 변경이다.

## 확인 결과

- Gitleaks 8.30.1 공식 배포본을 다운로드하고 공식 SHA-256 체크섬과 일치함을 확인했다.
- Gitleaks 기본 규칙으로 업로드 자료를 검사해 인증 정보 유출 패턴 0건을 확인했다. 도구는 비밀값을 가리는 모드로 실행했다.
- 개인 PC 경로, 이메일, 서버 IP, DB 접속 문자열, 운영 DB 이름과 실제 현장 식별값을 검사했다. 업로드용 필드 트리의 DB 이름은 `example_db`로 일반화하고 조회 날짜와 운영 스키마 원본 링크를 제거했다.
- 실제 사진·원본 데이터·환경 설정·인증 파일·서버 접속 도구는 업로드 목록에 포함하지 않았다.
- HTML은 외부 스크립트·스타일·이미지·폼을 사용하지 않는다. 화면 코드는 포함된 설계 정의를 읽어 표시하고 API 요청이나 DB 쓰기를 수행하지 않는다.
- 두 HTML의 조회·저장 정의가 일치하며 20개 테이블과 12개 업무, 61개 관계의 참조·필드와 JavaScript 문법을 확인했다. 문서의 내부 링크도 확인했다.

현재 GitHub 저장소는 공개 상태다. 이번 자료는 공개용 설계 사본이며 검사 결과는 이번 업로드 범위에 한정한다. 저장소 전체 이력의 보안 감사, 실제 서비스 침투 테스트, 운영 DB의 RLS·컬럼 권한 검증은 이번 검사 범위 밖이다. 정적 검사 통과가 모든 비밀정보나 취약점의 부재를 보장하지 않는다.
