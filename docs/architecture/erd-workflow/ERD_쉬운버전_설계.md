# ERD 쉬운 버전 설계와 구현 계획

목표는 기존 20개 테이블 설계를 업무 관점에서 읽는 HTML이다. 기존 상세 화면의 업무와 테이블 연결 정의를 가져오고, 설명과 배치를 쉽게 바꾼다.

- [x] 독립 HTML에 전체 흐름과 기존 12개 업무 버튼을 구성한다.
- [x] 전체 화면에는 공정표에서 작업을 나누고 AI 사진 분석과 현장 증빙을 각각 본사 검토로 모으는 흐름을 그린다.
- [x] 업무를 선택하면 받는 자료, 처리하는 주체, 저장되는 자료, 보는 결과를 표시한다.
- [x] 20개 테이블은 6개 자료 묶음으로 표시한다. 관련 묶음의 조회·저장을 강조하고 테이블명은 펼쳐서 확인한다.
- [x] 기존 상세 ERD로 연결하고 작은 화면용 메뉴·카드 배치를 구성한다. 12개 업무의 전환과 테이블 펼치기를 브라우저에서 확인한다.

화면의 업무 흐름은 연결 계획을 설명한다. DB 실행 결과와 운영 상태를 표시하는 화면은 아니다. 추가 라이브러리 없이 HTML·CSS·JavaScript로 구현한다.

검증 결과는 12개 업무마다 4단계와 6개 자료 묶음 표시, 테이블명 펼치기, 전체 흐름 복귀를 확인했다. 20개 테이블이 중복 없이 묶음에 포함되고 기존 업무별 조회·저장 정의를 유지하는지도 확인했다. 작은 화면은 반응형 배치를 구현했고 실제 모바일 기기 검증은 후속이다.
