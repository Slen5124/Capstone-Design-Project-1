# ERD와 업무별 데이터 흐름

매장 공사 관리 시스템의 데이터 구조와 업무별 입력·처리·저장·출력을 설명하는 설계 자료다.

## 보기

- [쉬운 버전 HTML](ALOHA_ERD_쉬운버전.html) — 업무 흐름과 자료를 6개 묶음으로 표시한다.
- [상세 ERD HTML](ALOHA_ERD_업무흐름.html) — 20개 테이블과 외래 키 관계, 전체 필드를 확인한다.

GitHub에서는 HTML 원문이 표시된다. 저장소를 내려받은 뒤 HTML 파일을 브라우저로 열면 버튼이 동작한다. HTML 두 개는 필요한 정의를 자체 포함하며 실행에 외부 라이브러리나 서버가 필요하지 않다. 관련 문서 링크도 사용하려면 이 폴더 전체를 함께 보관한다.

왼쪽 업무 버튼을 누르면 입력 자료부터 결과까지 흐름이 바뀐다. 쉬운 버전은 관련 자료 묶음을 강조하고, 상세 버전은 조회·저장 테이블을 색으로 구분한다. 상세 버전의 테이블을 누르면 전체 필드와 추가 이유를 볼 수 있다.

## 설계 상태

기존 11개 테이블과 질문 보관 1개, 후속 연동 8개를 합친 목표 20개 테이블이다. 후속 필드와 권한은 연결 계획이다. 화면 선택은 도식만 바꾸며 실제 DB 연결·데이터 변경·AI 실행을 수행하지 않는다.

AI 관측과 현장 담당자의 작업별 증빙을 별도 경로로 받고 본사가 검토한다. 주차별 보고서와 변경 요청·대화의 근거를 이력으로 연결한다. 벽·바닥·천장은 화면 설계의 관측 대상이며 실제 모델의 학습·검증 완료 범위는 [현재 비전 파이프라인](../../planning/current-vision-pipeline.md)을 따른다.

## 확인 방법

Node.js가 있으면 다음 명령으로 구조와 참조를 확인한다.

```sh
node docs/architecture/erd-workflow/verify-erd.cjs
```

브라우저에서는 12개 업무의 전환, 테이블 상세 표시와 쉬운 버전의 자료 묶음 펼치기를 확인한다.
