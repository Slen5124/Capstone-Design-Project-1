## 프로젝트 소개

Alo Yoga의 글로벌 매장 오픈 과정에서 여러 국가의 공사 진행 상황과 비용을 원격으로 파악할 수 있도록 AI 기반 관리 지원 방법을 검토하는 프로젝트입니다.

[2026년 9월 17일 기업 멘토 킥오프](docs/meetings/2026-09-17-client-kickoff.md)를 계기로 기존 고객 동선·Zone 분석에서 **글로벌 매장 공사 관리**로 방향을 전환했습니다. 현재는 **현장 사진과 공정표를 활용한 공정 모니터링**, **초기 조건과 과거 실적을 활용한 개략 공사비·견적 지원**의 두 과제를 검토합니다.

우선 구현할 과제와 기능 범위는 제공 가능한 데이터, 멘토 요구사항, 수행 기간을 확인한 뒤 팀 회의에서 정합니다.

## 검토 중인 과제

아래 내용은 킥오프에서 제안된 기능과 입력·출력 구상입니다. 실제 구현 범위와 기술 구성은 데이터 샘플 검토 후 확정합니다.

| 구분 | 과제 A · 현장 공정 모니터링 | 과제 B · 개략 공사비·견적 지원 |
| --- | --- | --- |
| 해결하려는 문제 | 해외 현장 방문과 시공사 보고에 의존하는 공사 현황 파악 | 국가·현장별 공사비와 공급업체 견적을 초기 단계에서 파악하기 어려움 |
| 주요 입력 | 촬영 시각·위치가 있는 현장 사진, 작업별 공정표, 주간 보고서 | 위치·면적·공사 범위·마감 수준, 과거 견적·실제 비용, 제공 가능한 도면·수량·사양 |
| 처리 흐름 | 시점별 사진 비교 → 변화·작업 상태 인식 → 공정표와 비교 → 진행 상황·지연 의심 검토 | 초기 조건·유사 사례 확인 → 개략 금액 범위 산출 → 공급업체 단가·납기 확인 및 견적 보정 |
| 예상 산출물 | 근거 사진과 계획 대비 상태를 포함한 공정 리포트 | 추정 근거·조건을 포함한 개략 공사비 범위와 공급업체 확인 내역 |
| 검증 시 구분할 항목 | 사진상의 변화 검출, 작업 상태 인식, 일정 지연 판단 | 개략 비용 추정값, 공급업체 회신 견적, 실제 집행 비용 |

정기 이메일 보고, 후속 질문·답변, 공사 문서 검색(RAG), 국가·시점별 가격 변동 반영도 제안되었습니다. 각 기능의 필요성과 구현 우선순위는 시범 범위를 정할 때 함께 검토합니다.

## 현재 진행 상황

**기준: 2026년 9월 18일 · 요구사항 정리 및 선행연구·제안서 준비 단계**

- **진행 완료:** 초기 저장소·협업 규칙 구성, 9월 17일 기업 멘토 킥오프 및 회의록 정리.
- **현재 준비:** 과제별 선행연구 2편씩 총 4편 조사, 입력·처리·출력 파이프라인, 데이터 요청 목록, 검증 계획 정리.
- **확인 예정:** 현장 사진·공정표·주간 보고서·과거 견적 등의 제공 범위와 시점, 모델·API 사용 조건, GPU 이용 방법.
- **다음 결정:** 먼저 시범 구현할 범위, 팀원별 개발 역할, 과제별 평가 지표와 일정.

`src/`와 `notebooks/`는 현재 구현·분석을 위한 기본 폴더만 마련된 상태입니다. 구현 결과와 실행 방법은 코드가 추가되면 갱신합니다.

### 데이터·기술 검토 기준

- **공정 모니터링:** 이미지의 촬영 위치·시각과 공정표의 작업·기간을 연결할 수 있는지 확인합니다. 진행률과 지연 여부의 정답 기준은 현장 자료를 바탕으로 정의합니다.
- **공사비·견적:** 지역·통화·기준일·면적·공종·사양 등 비용 비교 조건과 과거 실적의 제공 범위를 확인합니다.
- **모델·실행 환경:** 로컬 오픈소스 모델과 제공 GPU 활용을 검토합니다. 킥오프에서 제시된 최종 추론 단계의 상업용 AI API 사용 제한과 개발 단계 허용 범위는 재확인합니다.
- **평가:** 과제와 처리 단계별로 지표를 정하고, 현장·시간 단위의 데이터 분할과 독립 테스트 자료 확보 방법을 검토합니다.
