# 종합설계프로젝트 1

**Smart CCTV 데이터 기반 알로요가 매장 동선·존(Zone) 분석 및 오프라인 운영 최적화**

경북대학교 SW중심대학 학부생중심 산학협력프로젝트 · 2026학년도 2학기

## 프로젝트 소개

Alo Yoga 매장 고객의 이동과 체류 패턴을 분석하여 운영상 문제를 진단하고, 데이터에 근거한 개선 방향과 KPI 체계를 제안하는 프로젝트입니다.

매장 앞 통행량부터 실제 입장, Zone 체류·이동, 계산대 도달까지의 흐름을 중심으로 분석 방향을 검토합니다. 최종 구현 범위와 산출물은 멘토 요구사항과 제공 데이터에 맞춰 결정합니다.
