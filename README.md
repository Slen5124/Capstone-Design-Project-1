## 프로젝트 개요

알로요가 매장의 버카다(Verkada) CCTV·센서 데이터를 활용해 **존(Zone) 단위 체류·동선·전환 구조**를 진단하고,
Edge 서버 기반으로 실행 가능한 **매장 운영 최적화 가이드라인과 KPI 체계**를 수립한다.

기존 출입 인원 카운팅(Prodco Traffic Counter)은 "몇 명이 들어왔는가"만 알려줄 뿐,
"어디에 머물고, 얼마나 오래 보며, 어떤 동선으로 결제까지 이동하는가"를 설명하지 못한다는 문제의식에서 출발한다.

## 분석 과제

| # | 과제 | 핵심 내용 |
| --- | --- | --- |
| 1 | 방문 퍼널 분석 | 매장 앞 통행량 → 입장 → 순방문객 → 존 체류 단계별 이탈률, 유입률(Capture Rate) 기준선 설정 |
| 2 | 체류 귀속률 진단 | 총 체류시간 대비 미측정 시간 비율 산정, 피팅룸·계산대·중앙 통로 등 측정 사각지대 도출 |
| 3 | 존 진단 매트릭스 | 침투율(Penetration) × 평균 체류시간 2축 분석 → 스타존·통과존·틈새존·데드존 4분면 분류 |
| 4 | 동선 전환 네트워크 | 첫/마지막 방문 존 비율, 존 간 이동 분석으로 계산대 미도달 동선 규명 + 플로어 플랜 오버레이 |
| 5 | 고객 세그먼트 분석 | 성별·연령대·시간대·요일별 방문/체류 패턴, 피크 시간 기반 인력 배치 시뮬레이션 |
| 6 | 측정 정합성 검증 | 이중 집계·누락 카운터·중복 존 명칭·KPI 산출 오류 점검 자동화 리포트 |
| 7 | KPI 체계 및 재무효과 | 전략·운영·진단 3단계 KPI 프레임, 체류시간 탄력성 모델, 90일 실행 로드맵 |
| 8 | 브랜드 특성 반영 | 요가 클래스·커뮤니티 이벤트 시간대의 체류·전환 기여도, 온라인 채널 고객 여정 연계 |

자세한 내용은 [docs/proposal/README.md](docs/proposal/README.md) 참고.

## 기대효과

- 존별 체류·동선 데이터 근거의 진열/레이아웃 재배치 → 데드존 회복 및 객단가 상승
- 유입률 1%p 개선 효과 등 매장 외부 레버의 정량적 우선순위 도출
- 피크 시간·요일 기반 인력 운영으로 서비스 밀도 개선 및 인건비 효율화
- 추가 하드웨어 투자 없이 실행 가능한 90일 로드맵 확보
- 신규 매장 확장 시 재사용 가능한 성과 측정 표준(KPI 정의 + 정합성 검증) 수립

## 기술 스택

- **데이터 분석**: Python (pandas, numpy), 시계열/로그 처리
- **시각화·대시보드**: Matplotlib, Plotly, Tableau
- **컴퓨터 비전**: YOLO, DeepSORT 기반 객체 검출·트래킹, 존 카운팅
- **데이터 소스**: Verkada IP Camera, Edge Server, Prodco Traffic Counter
